# Portfolio — monteur vidéo

Site portfolio d'une seule page pour un monteur vidéo freelance.
HTML, CSS et JavaScript simples : rien à installer.

## Voir le site

Double-clique sur `index.html` : il s'ouvre dans ton navigateur.

## Fichiers

- `index.html` : le contenu (textes, liens, projets).
- `style.css` : l'apparence (couleurs, polices, mise en page).
- `script.js` : les animations (rideau d'ouverture, timecode, aperçu des projets, menu mobile).

## Personnaliser

Dans `index.html`, cherche les mentions **`À REMPLACER`** : chacune explique quoi changer
(ton nom, ta vidéo d'accueil, ton showreel, tes projets, ta photo, ton email et tes réseaux).
